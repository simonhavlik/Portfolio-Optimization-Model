A refresh re-downloads every 13F filing in the window, re-maps CUSIPs, reprices the tickers and rebuilds the board. It runs in the background and can take several minutes; the public page keeps serving the previous board until the new one is written. Scheduled refreshes run weekly overnight.

On history depth. The EDGAR column is everything on file for the filer — Baupost and Third Point go back to 1999. Only filings from 2013 onward carry a structured XML information table; earlier filings are plain-text or HTML tables and need a different parser. The board chains the twenty most recent quarters so a rebuild stays bounded; the admin view shows the full record we have access to.
